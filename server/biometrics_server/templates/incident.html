How to read the SHAP score

The model adds up evidence in log-odds. For this one window, SHAP splits the model's decision into one contribution per feature. A feature with SHAP +1.0 made "someone else is typing" about e1.0 ≈ 2.7× more likely than the model's average starting point, and +0.5 made it ≈ 1.6× more likely. Contributions add up, so several moderate features together can outweigh one large one.

Only features with a positive contribution (pointing away from the user) are listed. Features that looked like the user are left out.
